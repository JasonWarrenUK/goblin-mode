# Fonts for the spoils page

The page loads nothing from the network, so `warband.py` inlines these faces into it as data URIs when it draws the page. They are the latin subsets from `@fontsource` 5.3.0, the same faces the shared goblin theme names and the Pages site self-hosts.

| File | Family | Weight | Licence |
|---|---|---|---|
| `cabin-sketch-latin-700-normal.woff2` | Cabin Sketch | 700 | SIL OFL 1.1 |
| `special-elite-latin-400-normal.woff2` | Special Elite | 400 | Apache 2.0 |
| `ibm-plex-sans-latin-400-normal.woff2` | IBM Plex Sans | 400 | SIL OFL 1.1 |
| `ibm-plex-sans-latin-600-normal.woff2` | IBM Plex Sans | 600 | SIL OFL 1.1 |
| `ibm-plex-mono-latin-400-normal.woff2` | IBM Plex Mono | 400 | SIL OFL 1.1 |
| `permanent-marker-latin-400-normal.woff2` | Permanent Marker | 400 | Apache 2.0 |

Each family's licence text sits beside its files as `LICENSE-<family>.txt`.
