Every Human Need Goblin Mode

Claude Code is built for professional developers, and this needs to be rectified immediately. Here are five mods that can make your config more arcane, opaque and finicky.

Install

  1. Add the marketplace, once.

    claude plugin marketplace add JasonWarrenUK/goblin-mode
  2. claude plugin install goblin-seneschal@goblin-mode

Snacks

Two mods requiring almost no commitment. One files your complaints. The other is a goblin.

goblin-seneschal

Present Deficiency

When the tool annoys you, you are expected to get over it.

Remedy

Grievances are filed to a JSON log with the branch attached, and every session broadcasts a heartbeat every fifteen seconds. Readouts inform you of things you had been trusted to know for yourself.

Readout tell human what human cannot be trusted to know: which worktree human is standing in, what changelog say, if comma has lapsed, who is in the files and what human did one hour ago.

goblin-jester

Present Deficiency

The interface ships without a goblin and nobody has been held accountable.

Remedy

A goblin with nine moods, a sleep schedule and props, drawn by hand in box characters. It affects nothing.

Claude Code have NO goblin in it. Goblin check twice. So goblin put goblin in. Is 1,281 line of TypeScript. It change nothing Claude does. Is COOL.

Feasts

Three mods that each arrive with a config file, a protocol and a list of things you must never do. One has not been built, which has not reduced its paperwork.

goblin-scout

Present Deficiency

Your plan is a text file, which you are simply trusted to edit.

Remedy

Your plan is a roadbook: a JSON dependency graph you are forbidden to edit by hand. Twelve skills, a command line and a pane edit it for you.

Plan was just list. Human edit list with own hand. ANYONE could. Goblin put stop to this. If human tick box by hand, graph untick it at next recompute. Graph always win.

goblin-warband

Present Deficiency

Any session may use the database without applying for a permit.

Remedy

One session leads the others through a ledger of JSON files, timed dibs on the database and a numbered list of tribute for you to pay.

Four session on one repository and NOBODY in charge. Goblin fix. One session is chief. Each raider get own worktree, and dibs with time limit before it may touch database. There are thirteen rule. Goblin know all thirteen.

goblin-archivist

Present Deficiency

Your notes sit in Obsidian, unread by Claude, as though they were private.

Remedy

Every session reads your Obsidian vault, writes in it and files a note on each belief you hold so it can report when one has collapsed.

Human vault and human code live APART. Never meet. Goblin will end this. One spec. No code yet. Soon. Very soon.

Callouts

  1. F1, F6. The notice and its why: the lede carries the why; each mod's Deficiency and Remedy live in its folder (pin 5), so the ledger table is gone and nothing lists the mods twice. At 390 the notice drops its tape and meta line so the install slip is on the first screen (observation 19).
  2. R7. Dotted underlines mark every figure generated at build, including the counts in the lede and the schedule headers. The meta line uses the stamps' words (goblin-approved, soon). "Four session" is the story of the warband's first run, not a count of anything in the repository.
  3. F3, A2. The install slip, the one place that answers how to install: opening a folder switches its picker to that mod. It sits beside the notice, reading F4's "beside them" as beside the desk's contents, so it is on the first screen at 1280 and 390. The top row is split 3:2 and commands wrap at their spaces, so neither command hides behind a scroller.
  4. F4. A closed folder: numeral, name, what the mod does in plain words, and the status stamp. At 390 folders run as banded rows. The whole folder is the button; the page loads with every folder shut.
  5. F5. The open drawer: the mod's name, Deficiency and Remedy, the goblin's paragraph and the link to its page. Its notch points at the open folder, which gains an ink edge. One drawer at a time; the page scrolls by however far the closing drawer moved things, so the folder just pressed stays under the pointer. Without JavaScript each folder is a plain link to its page.
  6. R6. The goblin names each mod's own things by their real names (chief, raider, dibs, tribute); approved 2026-11-18.
  7. M3. goblin-archivist: proposed stamp on the folder, "Not yet installable" in the drawer and absent from the slip's picker.
  8. A1. The skills wing as a box file, for visitors who came to learn how to build their own. Titles are today's; each changes as its page is reworked. Sources live on each mod page (F6), not on the front page.
