Grievances are filed to a JSON log with the branch attached, and every session broadcasts a heartbeat every fifteen seconds. Five readouts inform you of things you had been trusted to know for yourself.

Callouts

  1. F1, F6. The notice and its why. The notice's why is the ledger (Mod, Present Deficiency, Remedy), so keeping one and dropping the other splits one object. Proposal: the lede carries the why on the front; each mod's Deficiency and Remedy move into its folder (pin 5).
  2. R7. Dotted underlines mark every figure generated at build: mod counts, the marketplace version, the commit. None is typed by hand.
  3. F3, A2. The install slip: the primary action, beside the notice so it is on screen without scrolling at 1280. The picker and every install line are generated from .claude-plugin/marketplace.json at build, so they list exactly what main ships. The site merges last, after every rename, so the new names are live on main before the page is.
  4. F4. A closed folder: numeral, name, one line and the status stamp. The whole folder is the button.
  5. F5. The open folder's drawer: Deficiency and Remedy, the goblin's paragraph, that mod's own install line and the link to its page. One drawer open at a time; at 1280 it lies under its row, at 390 directly under its folder. Without JavaScript each folder is a plain link to its page.
  6. R6, R8. Copy keeps the one goblin voice but names each mod's own things by their real names (chief, raider, dibs, tribute). Confirm, or keep the notice's original nouns.
  7. M3. goblin-archivist: proposed stamp, no install line.
  8. A1, S1. The skills wing as a box file, for visitors who came to learn how to build their own. Titles are today's; each changes as its page is reworked.
  9. F6, honesty rule. The sources leave the front page body but a collapsed slip stays as the footer, since every page carries its provenance. Each mod page carries its own sources.
