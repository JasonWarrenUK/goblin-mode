Level 2: Give It a Script and a Ledger

At level 1, tidy-imports was one file that asked Claude to sort a file's imports by hand. This level gives the sorting to a script, lets that one script run without a prompt and keeps a ledger of every file it touches.

2.1 Give It a Script

At level 1, Claude sorted the imports itself, and a model asked to reorder lines will now and then reflow one it was told to leave alone. A script does the same thing every time and costs no tokens, so the sorting moves into scripts/sort-imports.sh in the skill's folder.

Make the script executable once with chmod +x, then replace the three sorting lines in SKILL.md with an instruction to run it.

Its lines in SKILL.md are marked + 2.1 on the file sheet.

The new script, whole:

.claude/skills/tidy-imports/scripts/sort-imports.sh

#!/usr/bin/env bash# Sort the import lines at the top of a file, in place.set -euo pipefailfile="$1"# How many lines from the top start with "import "?count=$(awk '/^import /{n++; next} {exit} END{print n+0}' "$file")if [ "$count" -eq 0 ]; then	echo "no imports at the top of $file"	exit 0fi{ head -n "$count" "$file" | sort; tail -n +"$((count + 1))" "$file"; } > "$file.tmp"mv "$file.tmp" "$file"echo "sorted $count imports in $file"

2.2 Scope the Tool

Running a script is a Bash call, and Claude asks before each one unless the skill approves it. allowed-tools approves calls for as long as the skill runs; naming the script's full path, with :* for whatever arguments follow, approves that one script and no other command.

The rule matches the start of the command, so the body calls the script by exactly that path, with no bash or ./ in front.

Its lines in SKILL.md are marked + 2.2 on the file sheet.

2.3 Keep a Ledger

A ledger lets a later run say what an earlier one touched. The script appends one line per file to .claude/tidy-imports.log, the path and how many imports it sorted, so writing the ledger needs no extra permission.

SKILL.md tells Claude to read the ledger first and to leave the writing to the script.

Its lines in SKILL.md are marked + 2.3 on the file sheet.

The script after this step, with the two ledger lines marked:

.claude/skills/tidy-imports/scripts/sort-imports.sh

#!/usr/bin/env bash# Sort the import lines at the top of a file, in place.set -euo pipefailfile="$1"ledger=".claude/tidy-imports.log"# How many lines from the top start with "import "?count=$(awk '/^import /{n++; next} {exit} END{print n+0}' "$file")if [ "$count" -eq 0 ]; then	echo "no imports at the top of $file"	exit 0fi{ head -n "$count" "$file" | sort; tail -n +"$((count + 1))" "$file"; } > "$file.tmp"mv "$file.tmp" "$file"printf '%s\t%s\n' "$file" "$count" >> "$ledger"echo "sorted $count imports in $file"
