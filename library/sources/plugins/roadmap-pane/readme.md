# Roadmap Pane Plugin

> [!NOTE]
> Generated by `library/scripts/build-roadmap-plugin.py` from the sources in [goblin-mode](https://github.com/JasonWarrenUK/goblin-mode), beside the roadmap plugin. A mod: code that runs inside Claude Code and draws in the terminal.

---

## 1. Install

```sh
claude plugin marketplace add JasonWarrenUK/goblin-mode
claude plugin install roadmap-pane@goblin-mode
```

Requires Claude Code 2.1.287 or later and `python3` (3.8+, stdlib only) on `PATH`. The plugin carries its own copy of the roadmap CLI, so it works alone; enable `roadmap@goblin-mode` beside it for the skills, or run them from your own config.

---

## 2. `/ready`

Opens a pane with the ready set in leverage order, the claims in play and each milestone's progress, read from the `.claude/roadmaps.json` above the session's working directory. Running `/ready` again closes it. It runs inside Claude Code with no turn, so it works while Claude is busy.

| Key | Does |
|---|---|
| `1` to `9` | Picks a row. |
| `c` | Claims the picked task: asks who is doing it (a name is never inferred or pre-filled), then runs `claim <id> --assignee <name>`. The change is in `roadmaps.json`; commit it when you are ready. |
| `r` | Refreshes from the CLI. |
| Esc, or `/ready` | Closes the pane. |

The pane refreshes itself every two minutes while open and whenever a tool call touches `roadmaps.json` or runs the CLI. It is a tab beside any other pane, `/diff` included: Ctrl+X Tab moves the keyboard between panes, and only one shows at a time. In a fullscreen terminal of 110 columns or more it docks beside the transcript; narrower, it sits above the prompt.

---

## 3. Where Do I Find...?

| File | Path | Notes |
|---|---|---|
| Roadmap source of truth | `<project>/.claude/roadmaps.json` | found by walking up from the working directory, as every skill does |
| The CLI this plugin runs | `<plugin-root>/scripts/roadmap.py` | the same file the roadmap plugin ships, built from one source |
| The pane's code | `<plugin-root>/hooks/register.tsx` | its tests sit beside it; `claude plugin test <plugin-root>` runs them |
